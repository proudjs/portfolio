# Jutamat (Proud) Samnakbankok · Portfolio

UX/UI + Visual Designer in Milwaukee, WI. The signature is my own hand-drawn phut tan flower. It draws itself line by line, and smaller ones fall across the page and drift when you move your mouse.

Built with Claude. React, Vite and Tailwind, hosted on Vercel.

## Edit a case study
Each case study is one text file in `src/content/work/`. You can edit it right here on GitHub, even from the phone app. Saving it to `main` updates the live site in about a minute.

- The block at the top between the `---` lines fills the card and the page header.
- `## Label` starts a new section. `### Headline` is its red headline.
- `ready: true` makes the case study open on the site.
- Start a new one by copying `_template.md`.

## Run it on a computer
```bash
npm install
npm run dev
```
